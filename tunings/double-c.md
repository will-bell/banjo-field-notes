# Double C tuning

`gCGCD`

From 5th string to 1st string:

```text
5  g
4  C
3  G
2  C
1  D
```

## Things to learn here

- why this tuning lays out C-family melodies differently
- common C, F, and G shapes
- how scale degrees move compared with Open G
