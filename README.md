# Banjo Field Notes

A Markdown-first personal notebook and learning journal for banjo and music theory.

## Structure

- `journal/` — dated learning notes and self-explanations
- `theory/` — cleaned-up reference notes
- `tunings/` — tuning-specific notes
- `chord-charts/` — practical chord references
- `tunes/` — song-by-song study notes
- `lab/` — interactive experiments, eventually including Visual Banjo
- `recordings/` — small audio/video examples

## Local editing

Most content is just Markdown.

## GitHub Pages

This repository is set up for a project site at:

`https://will-bell.github.io/banjo-field-notes/`

Once GitHub Pages is enabled for the `main` branch, the site should publish from the repository root.

## Philosophy

Journal entries preserve the original thought process, including mistakes. Reference pages can evolve into cleaner explanations later.
